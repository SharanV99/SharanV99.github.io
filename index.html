01 / R · LASSO REGRESSION

Boston 311 Service Requests

Question
What actually drives how long the City of Boston takes to resolve a service request, and is the city getting faster?
Approach
Cleaned 1.3M service requests in R and engineered 31 features, including geospatial and temporal variables. Used LASSO regression to isolate the drivers of resolution time, with stepwise regression as a check.
Finding
Requests submitted through the City Worker App were resolved 284 hours faster than those from consumer-facing channels. Average response time improved 13% year over year (119 hours per year, p < 0.001).
Recommendation
Expand employee training and City Worker App adoption, since the internal channel is where the speed gains are.
02 / RAG · LANGCHAIN · KUBERNETES

GenAI Travel Analytics Platform

Question
How do you stop a travel assistant from confidently answering questions about matches or dates that don’t exist?
Approach
Built a “hallucination firewall” into a LangChain RAG pipeline that checks each query against official FIFA schedules and blocks invalid matches or dates before generation. Ran the services on Kubernetes (Minikube) with self-healing pods, and used the ELK Stack to capture application logs.
Result
Failure recovery time dropped from 15+ minutes to under 10 seconds. Kibana dashboards tracked user search intent and API latency in real time.
Takeaway
Validating inputs before generation is a cheaper, more reliable guardrail than trying to catch bad answers afterward.
03 / PYTHON · IN PROGRESS

Last.fm Churn Propensity

Question
Can listening history predict which users are about to go silent on the platform, and who is worth targeting to win back?
Done so far
Set up secure API access and wrote a paginated fetch script for the Last.fm recent-tracks API. Defined churn at the platform level (a user going silent overall) rather than per artist, so the model predicts real disengagement.
Next
Feature engineering, time-based train/test splits, probability calibration, expected-value targeting, and an experiment design with power analysis.
